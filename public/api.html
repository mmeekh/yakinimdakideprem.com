Deprem API

JSON çıktısı ile “anlık deprem” ve “son depremler” verilerini almak için /api/earthquakes endpointini kullanın. Aşağıda parametreler ve örnek istekler yer alıyor.

Endpoint

GET https://yakinimdakideprem.com/api/earthquakes

Parametreler

  • hours_back (int, varsayılan 24): Kaç saat geriye gidilecek.
  • min_magnitude (float, varsayılan 2.0): Minimum büyüklük filtresi.
  • limit (int, varsayılan 100): Döndürülecek maksimum kayıt sayısı.

Örnek cURL

curl \"https://yakinimdakideprem.com/api/earthquakes?hours_back=72&min_magnitude=3.0&limit=20\"

Örnek JS

fetch('/api/earthquakes?limit=10')
  .then(res => res.json())
  .then(data => console.log(data.data));

Swagger/OpenAPI dokümantasyonu için: /docs
